### Detailed Description (для карточки в Chrome Web Store)

> Важно: без технических деталей реализации и без упоминания внешних сервисов.

```text
Clipboard — локальный менеджер буфера обмена прямо в браузере. Он запоминает скопированный текст, ссылки, картинки и видео, чтобы вы могли быстро найти нужное и вставить в пару кликов.

Что умеет расширение:
• Быстрая панель поверх любой страницы по нажатию Alt+V (работает и на английской, и на русской раскладке).
• Автоматическое сохранение скопированного текста и сохранение картинок, видео и ссылок через контекстное меню.
• Перетаскивание (drag-and-drop) сохранённых картинок и видео прямо в поля загрузки на сайтах, а также быстрая вставка текста в активное поле.
• Закрепление важных записей: закреплённые элементы не уходят в архив и не удаляются при автоматической очистке по сроку хранения.
• Поиск по истории и фильтры по категориям: Текст, Ссылки, Фото, Видео, Закреплённые и Архив.
• Оптимизация места: настройка лимита активной ленты с переносом старых записей в архив и сжатие старых незакреплённых фото.
• Список исключений для сайтов и полная блокировка захвата полей ввода пароля.
• Экспорт и импорт резервной копии всей истории в локальный файл на вашем компьютере.

Режимы отображения:
• Плавающая панель на странице (Alt+V)
• Всплывающее окно по клику на иконку расширения
• Боковая панель браузера (Side Panel)
• Отдельное компактное окно

Приватность:
Вся история и настройки хранятся только локально в вашем браузере. Расширение не требует регистрации, не отправляет данные на сторонние серверы и не собирает аналитику.
```

## Single Purpose Description (Единственное назначение)

`Локальное сохранение, поиск, организация и быстрая вставка истории буфера обмена (текста, ссылок, изображений и видео) полностью внутри браузера без отправки данных вовне.`

## Обоснование разрешений (Permission Justifications)

| Разрешение | Обоснование для ревьюеров Chrome Web Store |
|---|---|
| `storage` | Локальное хранение пользовательских настроек (режим окна, лимиты ленты, исключённые домены, срок хранения). |
| `unlimitedStorage` | Снятие стандартного ограничения браузера, чтобы пользователь мог хранить в локальной истории изображения и видеофайлы. |
| `contextMenus` | Добавление пунктов «Сохранить текст», «Сохранить картинку», «Сохранить видео» и «Сохранить ссылку» в контекстное меню правой кнопки мыши. |
| `clipboardRead` | Чтение скопированных пользователем изображений или текста из системного буфера при открытии панели расширения или ручной вставке. |
| `clipboardWrite` | Копирование выбранной записи из истории обратно в системный буфер обмена по клику на карточку или кнопку копирования. |
| `activeTab` | Вставка выбранного текста в активное поле на текущей вкладке, отправка всплывающих уведомлений и открытие панели поверх страницы. |
| `tabs` | Определение текущей вкладки для передачи сообщений об открытии плавающей панели, тост-уведомлений и списка исключений по домену. |
| `scripting` | Инъекция сценария для открытия панели или показа уведомлений, если страница была открыта до установки расширения или перегружена. |
| `sidePanel` | Поддержка режима боковой панели браузера Chrome по выбору пользователя. |
| `<all_urls>` | Работа горячей клавиши `Alt+V`, автозахвата копирования на любой открытой пользователем веб-странице (кроме системных страниц и списка исключений), а также скачивание картинки или видео по явному клику в контекстном меню. |

- **Remote Code**: `No, I am not using remote code` (весь JavaScript, CSS и шрифты локально упакованы внутри архива расширения).

## Декларация конфиденциальности (Privacy Practices / Data Usage)

При заполнении вкладки **Privacy** в Chrome Web Store Developer Dashboard:
- **Does your extension collect user data?**: `No` (данные не собираются и не передаются разработчику или третьим лицам; вся история находится исключительно в локальном хранилище устройства).
- Отметить все три обязательные декларации в Developer Dashboard:
  1. I do not sell or transfer user data to third parties, outside of the approved use cases.
  2. I do not use or transfer user data for purposes that are unrelated to my item's single purpose.
  3. I do not use or transfer user data to determine creditworthiness or for lending purposes.
