Возможности

Текст, фото, видео

Текст сохраняется при Ctrl+C. Картинки и видео — через правую кнопку, вставкой или перетаскиванием файлов.

Закреп

Важные записи остаются наверху и не удаляются автоматически, пока вы сами их не уберёте.

Архив и поиск

Старые записи уходят в архив, а поиск и фильтры находят нужное за секунду.

Автоудаление

Задайте срок в днях: незакреплённые записи старше этого срока удалятся автоматически.

Исключения сайтов

Список сайтов, где автосохранение выключено. Пароли из полей ввода не сохраняются никогда.

Резервная копия

Экспорт и импорт всей истории в один файл. Перенос на другой компьютер за минуту.

Данные остаются у вас

История хранится в IndexedDB вашего браузера и никуда не отправляется. При удалении расширения все данные стираются с диска.

Alt+V

Alt+V на любой странице

Окно появляется поверх сайта, управляется с клавиатуры: стрелки, Enter для вставки и Esc для выхода. Можно открыть и боковую панель.

Установить Clipboard

Версия 1.2.0 · ~150 КБ. Бесплатно, с открытым исходным кодом и без регистрации.

Для Chrome и Chromium

clipboard-extension-v1.2.0.zip · Chrome, Edge, Brave, Opera, Яндекс

Скачать для Chrome (.zip)
  1. Распакуйте архив в любую постоянную папку
  2. Откройте chrome://extensions и включите «Режим разработчика»
  3. Нажмите «Загрузить распакованное расширение» и выберите папку
  4. Закрепите иконку на панели и нажмите Alt+V на любой странице

Для Firefox

clipboard-firefox-v1.2.0.zip · Firefox 140+

Скачать для Firefox (.zip)
  1. Откройте about:debugging#/runtime/this-firefox
  2. Нажмите «Загрузить временное дополнение…»
  3. Выберите скачанный архив clipboard-firefox-v1.2.0.zip

Заявки в Chrome Web Store и Firefox Add-ons (AMO) готовятся к публикации; исходный код доступен на GitHub.

Частые вопросы

Куда уходят мои данные?

Никуда. История хранится в IndexedDB вашего браузера. У расширения нет сервера, аккаунтов, аналитики и рекламы.

Не сохраняет ли оно пароли?

Нет. Содержимое полей ввода пароля игнорируется, а для чувствительных сайтов можно выключить автосохранение в настройках.

Зачем расширению доступ ко всем сайтам?

Чтобы перехватывать событие копирования и показывать окно по Alt+V на любой странице. Информация о посещённых сайтах нигде не сохраняется и не передаётся.

Как перенести историю на другой компьютер?

В настройках нажмите «Экспорт в файл», затем на другом компьютере «Импорт». Фото и видео переносятся вместе с текстом.

Какие браузеры подходят?

Chrome 114 и новее (Edge, Brave, Opera, Яндекс Браузер), а также Firefox 140 и новее.
